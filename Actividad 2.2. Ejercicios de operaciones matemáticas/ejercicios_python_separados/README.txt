EJERCICIOS PYTHON SEPARADOS

Archivos:
- main.py: menú principal para seleccionar los ejercicios.
- ejercicio1.py: sumatorio.
- ejercicio2.py: factorial.
- ejercicio3.py: potencia.
- ejercicio4.py: triángulo de Pascal.

Cómo usar:
1. Mantén todos los archivos en la misma carpeta.
2. Abre una terminal en esa carpeta.
3. Ejecuta: python main.py

También puedes ejecutar un ejercicio individualmente, por ejemplo:
python ejercicio1.py

Cada archivo de ejercicio tiene su propia función y la condición
if __name__ == "__main__": para que al importarlo desde main.py
no se ejecute automáticamente.
